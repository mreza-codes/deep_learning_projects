# Cats vs Dogs Classification (PyTorch)

This repository contains a simple Convolutional Neural Network (CNN) built with PyTorch to classify images of cats and dogs. The project uses the Kaggle *PetImages* dataset and includes a complete training pipeline, evaluation, and sample predictions.

##Link to Dataset:
https://www.microsoft.com/en-us/download/details.aspx?id=54765&utm_source=copilot.com

## Features
- Custom CNN architecture implemented in PyTorch  
- Training and validation loops  
- Accuracy evaluation on test data  
- Sample image prediction (4 test images included)  
- Clean and readable Jupyter Notebook workflow  

## How to Use
1. Download the **PetImages** dataset from Kaggle.  
2. Place the `PetImages` folder in the same directory as the notebook.  
3. Open and run the `cnn_cats_vs_dogs.ipynb` notebook step by step.  
4. Four sample test images (`1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`) are included for quick inference.  
   You may replace them with your own images if desired.

## Requirements
- Python 3.10+
- PyTorch
- torchvision
- matplotlib
- pillow
